# 🧩 Pokémon Explorer

Pokémon Explorer is a simple and responsive web app built with **Next.js** and **Tailwind CSS**.

It lets you:
- 🧬 Browse the first 151 Pokémon
- 🔍 Search Pokémon by name
- 📄 Click on a Pokémon to view detailed info like types, stats, abilities, and moves

All data is fetched live from the [PokeAPI](https://pokeapi.co/). No backend required — just frontend magic!

---

## 🚀 How to Run This Project

```bash
# 1. Clone the repository
git clone https://github.com/nayana2627/Pokemon-Explorer.git
cd Pokemon-Explorer

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Open in browser
http://localhost:3000
